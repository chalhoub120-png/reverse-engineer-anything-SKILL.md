# تطبيق توصيل طلبات متل Toters (نسخة تجريبية)

تطبيق كامل لتوصيل الطلبات (مطاعم، سوبرماركت، صيدلية) بلغة عربية ودعم RTL، يتكون من:

- **الواجهة الأمامية**: React + Vite + Tailwind CSS + React Router (المنفذ 5173)
- **الخادم**: Node.js + Express + SQLite (قاعدة بيانات محلية ملف واحد) (المنفذ 5000)
- **أدوار المستخدمين**: زبون، صاحب متجر، سائق توصيل، مشرف نظام

## المميزات

### للزبون
- تسجيل دخول / إنشاء حساب
- تصفح المتاجر والتصنيفات والبحث
- عرض قائمة المتجر وإضافة منتجات للسلة مع التحكم بالكمية
- إتمام الطلب مع تحديد العنوان والهاتف وطريقة الدفع
- تتبع حالة الطلب خطوة بخطوة (قيد الانتظار → مؤكد → قيد التحضير → جاهز → في الطريق → تم التوصيل)
- عرض سجل الطلبات السابقة

### لصاحب المتجر
- لوحة تظهر طلبات متاجره فقط
- تحديث حالة الطلب (تأكيد، تحضير، جاهز للتسليم، إلخ)

### للسائق
- عرض الطلبات الجاهزة للتسليم وقبولها
- تحديد "تم التسليم" عند الانتهاء

### للمشرف
- إحصائيات عامة (المستخدمون، المتاجر، الطلبات، الإيرادات)
- إدارة المستخدمين والمتاجر وعرض جميع الطلبات

## طريقة التشغيل

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)

### الخطوات

```bash
# entrada إلى مجلد المشروع
cd reverse-engineer-anything-SKILL.md

# تشغيل الخادم
cd backend
npm install
npm start        # أو npm.dev للتطوير مع إعادة التشغيل التلقائي
# الخادم سيعمل على http://localhost:5000 وسيزود قاعدة البيانات ببيانات تجريبية تلقائياً

# في محطة جديدة، تشغيل الواجهة
cd ../frontend
npm install
npm run dev      # الواجهة سيعمل على http://localhost:5173
```

ثم افتح المتصفح على `http://localhost:5173`.

### ملاحظات
- الصور تُرفع وتُخزَّن في `backend/uploads/` وتُقدَّم كملفات ثابتة.
- قاعدة بيانات SQLite تُنشأ تلقائياً في `backend/data/app.db` عند أول تشغيل، وتُزرع ببيانات تجريبية إذا كانت فارغة.
- لتعطيل CORS المقيد في بيئة الإنتاج، عدل متغير `FRONTEND_URL` في ملف `.env` للخادم.

## بنية الملفات

```
backend/          # خادم Node + Express + SQLite
  server.js       # نقطة الدخول وكل مسارات API
  db/schema.sql   # هيكل قاعدة البيانات
  db/seed.js      # بيانات تجريبية أولية
  middleware/auth.js  # فحص التوكن والصلاحيات (JWT)
  data/app.db     # قاعدة البيانات (تُنشأ تلقائياً)
  uploads/        # صور المنتجات والمتاجر
frontend/         # واجهة React + Vite
  src/
    pages/        # صفحات التطبيق (الرئيسية، المتجر، السلة، الدفع، التتبع، اللوحات)
    contexts/AuthContext.jsx   # إدارة جلسات المستخدم
    api.js        # إعداد Axios مع توكن المصادقة
    components/   # شريط التنقل، مسارات محمية، إلخ
```
